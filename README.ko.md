## 소개

새로운 발견과 기술로 세상을 바꾸는 과학자들을 보며 저도 그런 변화를 만들어 보고 싶었습니다. 그 마음으로 인공지능을 배우기 시작했고, 아이디어를 코드로 만들고 실험하며 예상과 다른 결과의 원인을 확인합니다. 제가 꿈꾸는 미래를 더 많은 사람이 일상에서 함께 누릴 수 있도록 배움과 도전을 이어가고 있습니다.

맨체스터대학교에서 인공지능을 공부했습니다. 언어 모델과 정보 검색, 효율적인 모델 학습, 탐색 알고리즘, 백엔드 시스템과 물리 시뮬레이션을 프로젝트로 구현하고 있습니다.

## 관심 분야

- **Embodied AI와 로보틱스:** 인식과 학습, 제어를 연결해 지능이 실제 행동으로 이어지는 방식을 탐구하고 싶습니다.
- **자율주행:** 주변 상황을 인식하고 스스로 판단해 안전하게 이동하는 시스템에 관심이 있습니다.
- **로켓공학:** 발사와 회수에 필요한 물리, 유도 및 제어 원리를 공부하고 있습니다.
- **AI 시스템:** 도움이 되는 애플리케이션을 만들고 실험으로 동작을 확인하는 과정에 관심이 있습니다.

## 프로젝트

아이디어를 구현하고 실험으로 확인한 과정을 각 저장소에 정리했습니다.

- **[포트폴리오 웹사이트](https://park-dongmyung.com/)** — 프로젝트 소개, 실험 결과, 소스 링크와 재현 방법을 정리했습니다.
- **[동일 저자 판별](https://github.com/Dongmyung378/NLU-Authorship-Verification)** — 영어 글 두 편의 저자를 판별하는 공동 NLP 프로젝트로 트랜스포머와 문체 모델을 비교했습니다.
- **[한국어 검색 기반 질의응답](https://github.com/Dongmyung378/Korean-NLP-RAG)** — 근거 검색과 답 추출을 구현하고 검색 모델 및 읽기 문맥 구성을 같은 조건에서 비교했습니다.
- **[지식 증류](https://github.com/Dongmyung378/Knowledge-Distillation)** — 경량 교통 표지판 분류 모델의 반복 실험, 오류와 CPU 추론 비용을 분석했습니다.
- **[Hex 탐색 에이전트](https://github.com/Dongmyung378/AI-and-Games)** — 몬테카를로 트리 탐색과 RAVE-TS, 전술 규칙과 CPU 예산을 비교했습니다.
- **[DM100 로켓 시뮬레이션](https://github.com/Dongmyung378/DM100-2D-Rocket-Recovery)** — 물리 모델과 유도 및 상태 추정을 연결한 2차원 발사와 회수 시뮬레이터입니다.
- **[기호 머신러닝](https://github.com/Dongmyung378/Knowledge-Based-AI)** — 결정 트리와 FOIL로 읽을 수 있는 분류 기준과 재귀 관계를 학습합니다.
- **[논문 질의응답과 근거 추적](https://github.com/Dongmyung378/Evidence-Grounded-Paper-QnA)** — 영어 논문에 한국어와 영어로 질문하고 답변 문장별 인용 원문을 대조합니다.
- **[채팅과 예약 시스템](https://github.com/Dongmyung378/Distributed-System)** — 독립된 TCP 채팅과 HTTP 예약 애플리케이션의 느린 연결 격리와 복구를 구현했습니다.
- **[EventLite](https://github.com/Dongmyung378/Event-Website)** — 행사 관리 팀 프로젝트이며 테스트, 보안과 주요 관리 기능 구현에 참여했습니다.
- **[상황 인식형 NPC](https://github.com/Dongmyung378/Context-Aware-Npc-System)** — Unreal Engine에서 일과, 규칙 기반 대화, 퀘스트, 거래, 신뢰도와 동행을 연결했습니다.
